# 로드맵

## 1단계 (현재)

- Flutter Web 반응형 사이트
- 로컬 규칙 기반 생명구조 엔진
- 12개 메뉴와 필수 시나리오 분기
- 로컬 저장·삭제, 출처 정책 골격
- 유료 API·Firebase 비용 서비스 미연결

## 2단계

- 검증된 공식 문서 RAG
- 위치·기상 결합(사용자 동의 기반)
- 가족 알림 설계(전송 전 명시 확인)
- 접근성·다국어·오프라인 캐시 강화

## 3단계

- 웨어러블·CCTV·센서 이상탐지
- PLC / Modbus RTU·TCP / MFC 관제 연동
- 엣지 AI·로컬 PC 오프라인 관제

## 4단계

- 공식 기관 연동(법적·운영 승인 범위)
- Human-agent 협업 워크플로
- 품질·편향·오판 모니터링
