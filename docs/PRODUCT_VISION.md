# SotongSaveLive 제품 비전

## 한 줄 정의

사용자가 질병·사고·재난·폭력·정신적 위기·생활 붕괴 등 생명이 위태로워질 수 있는 상황을 제대로 설명하지 못해도, AI가 상황을 단계적으로 파악하고 위험도를 판단하며 지금 해야 할 행동, 도움 요청 방법, 구조기관·보호자 전달문, 구조 완료까지의 추적계획을 구성하는 AI 생명구조 플랫폼.

## 하지 않는 것

- 응급처치 백과사전/뉴스/블로그형 정보 포털
- 작동하지 않는 AI를 작동하는 것처럼 꾸미기
- 의료진·구조대·경찰 대체 표현
- 근거 없는 진단·생존율·임의 기관/전화번호 생성

## 사용자 가치

1. 말이 안 나와도 시작할 수 있음
2. 가장 위험한 것부터 확인
3. 지금 할 일 하나 + 하면 안 되는 일
4. 전달문을 바로 복사
5. 끝난 뒤 재발방지까지 연결

## 차별화

농촌·산업현장(PLC·센서·Modbus·오프라인 관제)과 가족·고령자 안부, 위험예측을 하나의 생명구조 흐름으로 연결합니다.
