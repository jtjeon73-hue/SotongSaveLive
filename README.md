# SotongSaveLive

AI 생명구조 플랫폼 — 사용자가 위기 상황을 제대로 설명하지 못해도, 로컬 AI 엔진이 상황을 단계적으로 파악하고 위험도·행동계획·상황보고서·추적계획을 구성합니다.

> **중요:** 이 서비스는 의료진·구조대·경찰을 대신하지 않습니다. 생명이 위급하면 즉시 공식 긴급구조에 연결하세요.

## 일반 안전정보 사이트와 다른 점

- 질병 백과·응급처치 문서 나열이 아닙니다.
- 정해진 챗봇 답변 반복이 아닙니다.
- 입력에 따라 **질문·위험도·행동·금지행동·보고서**가 실제로 달라지는 규칙 기반 엔진이 동작합니다.
- 질환 확정 진단, 약물·용량 지시, 생존율 백분율 예측, 임의 전화번호 생성을 하지 않습니다.

## 현재 구현된 AI 역할 (1단계)

1. 위기상황 파악 (한 번에 하나씩 질문)
2. 생명위험 가능성 보수적 판별
3. 개인·상황별 행동계획 / 금지행동
4. 보호자·구조 전달용 상황보고서
5. 상태 변화·종료 후 재발방지 계획
6. 위험예측·농촌·산업 센서 샘플 시뮬레이터

## 1단계 로컬 엔진의 한계

- 외부 생성형 AI API **미연결**
- 음성·사진·자동 위치·웨어러블·CCTV·실제 PLC/Modbus **미연결** (UI에 “향후 연결 예정” 표시)
- 자동 신고·문자·전화 전송 **없음**
- 공식 의료지침 전문 검토 전 상세 치료 지시 **없음**

## 실행 방법

```bash
flutter pub get
flutter run -d chrome
```

```bash
flutter test
```

## 빌드 방법

```bash
flutter build web --release
```

빌드 산출물: `build/web`

## 데이터·개인정보 원칙

- 1단계 데이터는 브라우저 로컬(`shared_preferences`)에만 저장
- 외부 전송·Firebase Auth/Firestore/Functions **미사용**
- 민감정보 저장 전 동의, 신뢰센터에서 전체 삭제 가능

## 향후 연동 구조

화면과 분리된 인터페이스를 준비했습니다.

- `ExternalAiProvider` — 생성형 AI
- `LocationProvider` / `WeatherProvider`
- `SensorDataProvider` — IoT/PLC
- `NotificationContactProvider` — 알림·연락

현재는 로컬 구현체·샘플 데이터만 사용합니다. **비용 발생 가능 서비스는 연결하지 않았습니다.**

## 단계별 로드맵

자세한 내용: [docs/ROADMAP.md](docs/ROADMAP.md)
