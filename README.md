# SotongSaveLive

AI 인생·노후설계 플랫폼 — 질문을 받지 않고, 이미 준비된 인생 유형과 미래 시나리오를 읽으며 자신의 삶을 설계하도록 돕습니다.

> 오래 사는 것보다 중요한 것은  
> 남은 시간을 나답게 살아가는 것입니다.

## 이 사이트가 하지 않는 것

- 설문·채팅·개인정보·자산·건강 입력
- 회원가입·로그인·프로필 저장
- 위기상황 질문·구조 지휘(구 생명구조 콘셉트 제거)
- 확정적인 의료·세무·법률·투자 개인 맞춤 조언

## 7개 메뉴

1. 홈  
2. 다섯 가지 인생  
3. AI 인생로드맵  
4. 돈과 평생일  
5. 건강·관계·생활  
6. 농촌과 제2의 인생  
7. 아름다운 마무리  

## 실행

```bash
flutter pub get
flutter run -d chrome
```

## 테스트·빌드

```bash
flutter test
flutter build web --release
```

## 데이터·출처

- 로컬에 검토된 시나리오·콘텐츠만 사용
- 외부 생성형 AI API·Firebase Functions/Firestore·유료 서비스 미연결
- 제도·금액은 변경될 수 있으므로 공식 출처와 확인일을 표시
- 금액 예시는 **가상 대표 사례**이며 공식 수급액이 아님
